# Week 4 — Mini Incident Response Plan

**Training Institute:** Vortex Tech Academy  
**Program:** Cyber Security Internship Track  
**Project:** Mini Incident Response Plan  
**Scenario:** NovaCart Online — Fictional Customer Data Exposure

## Project Overview

This project documents a structured incident response plan for a fictional e-commerce company experiencing unauthorized access to a customer-data export API.

The project applies the six-phase incident response lifecycle specified in the Vortex Week 4 assignment.

## Incident Response Lifecycle

1. **Preparation** — Asset inventory, response-team roles, monitoring readiness, and backup/restore exercises.
2. **Detection & Analysis** — Simulated API logs, SIEM alert investigation, incident timeline, and evidence verification.
3. **Containment** — Simulated API key revocation, endpoint restriction, and access verification.
4. **Eradication** — Server-side authorization remediation and role-based access testing.
5. **Recovery** — Backup integrity checks, service restoration, and post-recovery monitoring.
6. **Lessons Learned** — Blameless review and improvement action tracking.

## Communication & Prevention

- Internal incident communication matrix.
- Customer notification draft.
- Stakeholder responsibilities and escalation.
- Server-side API authorization.
- Automated API authorization tests.
- SIEM monitoring for unusual data exports.
