# NovaCart Incident Response Team

## 1. Incident Commander
- Leads the incident.
- Assigns responsibilities.
- Coordinates response decisions.

## 2. SOC Analyst
- Monitors SIEM alerts.
- Investigates logs.
- Preserves evidence.
- Builds incident timeline.

## 3. System Administrator
- Manages server access.
- Supports approved containment.
- Preserves system logs.

## 4. API Developer
- Investigates API security weaknesses.
- Fixes missing authorization checks.
- Tests the corrected API.

## 5. Database Administrator
- Protects customer databases.
- Reviews database access.
- Supports backup restoration.

## 6. Legal / Privacy Team
- Assesses legal obligations.
- Advises on breach notification.

## 7. Communications Team
- Prepares approved incident communications.

## Escalation
SOC Analyst -> Incident Commander -> Technical Teams
-> Legal / Privacy -> Approved Communications
