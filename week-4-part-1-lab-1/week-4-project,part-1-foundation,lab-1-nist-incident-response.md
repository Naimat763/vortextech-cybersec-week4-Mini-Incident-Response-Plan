## NIST Incident Response Framework

Training: Vortex Tech Academy

### What is Incident Response?
Incident Response is the process of identifying,
containing, investigating and recovering from
cybersecurity incidents.

### Six Incident Response Phases

1. Preparation
   Prepare the incident response team, backups,
   monitoring and security tools.

2. Detection and Analysis
   Detect suspicious activity and investigate
   the security incident.

3. Containment
   Stop the incident from spreading further.

4. Eradication
   Remove the root cause and malicious access.

5. Recovery
   Restore affected systems safely and monitor them.

6. Lessons Learned
   Review the incident and improve security controls.

### Example Scenario
A fictional e-commerce company experiences
unauthorized access to a customer database
through an unsecured API endpoint.

### Main Learning
Incident Response helps organizations reduce
the impact of security incidents and restore
normal business operations.
