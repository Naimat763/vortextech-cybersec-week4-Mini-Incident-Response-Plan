# Week 4 - Mini Incident Response Plan

**Institute:** Vortex Tech Academy
**Program:** Cyber Security Internship Track

## Project Overview

This project presents a fictional e-commerce
customer-data exposure scenario and a structured
incident response plan.

## Framework

NIST Incident Response Lifecycle:

- Preparation
- Detection and Analysis
- Containment
- Eradication
- Recovery
- Lessons Learned

## Key Areas

- Incident investigation
- Evidence preservation
- Response-team responsibilities
- Internal and external communication
- Preventive security controls
- Post-incident improvement

## Training Environment

Ubuntu Linux and controlled local simulations.

## Scope

This is an educational fictional scenario.
No real production system or customer data
was accessed.
